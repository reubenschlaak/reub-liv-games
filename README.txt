# Reub + Liv Game Collection

A mobile-friendly, single-page game website.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository named `reub-liv-games`.
2. On the repository page, choose **Add file → Upload files**.
3. Upload `index.html` from this folder and commit the changes.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a minute or two. GitHub will show your website URL in the Pages section.

## Add it to iPhone
1. Open the published website URL in Safari.
2. Tap the Share icon.
3. Choose **Add to Home Screen**.
4. Name it `Reub + Liv` and tap **Add**.

## Notes
- This first version stores saved questions, scores, and round count in the browser's local storage. That means data stays on the device/browser where it was created.
- The website itself is public if the GitHub repository is public. Do not put private information in it.
- Cross-device shared syncing and custom question editing can be added later with a database/backend.
